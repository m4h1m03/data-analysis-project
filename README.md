# British Airways Customer Reviews — Data Analysis

Exploratory data analysis and cleaning of ~2,500 British Airways customer reviews (Skytrax-style), covering ratings, seat class, travel type, and review text.

## Goals
- Practice an end-to-end data analytics workflow: import, clean, engineer features, explore, visualize, and test hypotheses
- Build a portfolio project using Python, pandas, and Jupyter
- Version-controlled with Git

## Project structure
- `data/raw/` — original, unmodified dataset
- `data/processed/` — cleaned dataset (generated by notebook 1)
- `notebooks/01_import_eda_cleaning.ipynb` — importing, cleaning, and initial EDA
- `notebooks/02_feature_engineering_eda.ipynb` — feature engineering, further EDA and visualizations, and hypothesis testing

## Key findings
- Average star rating has stayed essentially flat from 2015–2023, though this is scoped by a known scraping limitation restricting `stars` to odd values only
- No statistically significant relationship between review length and star rating (Kruskal-Wallis H-test, p ≈ 0.991)
- Reviewers who did not recommend British Airways wrote significantly longer reviews on average than those who did (Mann-Whitney U test, p ≈ 8.28 × 10⁻²¹)
