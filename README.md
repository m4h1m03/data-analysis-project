# British Airways Customer Reviews — Data Analysis

Exploratory data analysis and cleaning of ~2,500 British Airways customer reviews (Skytrax-style), covering ratings, seat class, travel type, and review text.

## Goals
- Practice an end-to-end data analytics workflow: import, clean, engineer features, explore, visualize, and test hypotheses
- Build a portfolio project using Python, pandas, Jupyter, and SQL (PostgreSQL on Supabase)
- Version-controlled with Git

## Project structure
- `data/raw/` — original, unmodified dataset
- `data/processed/` — cleaned dataset (generated by notebook 1)
- `notebooks/01_import_eda_cleaning.ipynb` — importing, cleaning, and initial EDA
- `notebooks/02_feature_engineering_eda.ipynb` — feature engineering, further EDA and visualizations, and hypothesis testing
- `sql/` — SQL queries run on PostgreSQL (Supabase): column exploration, date cleaning, and rating analysis

## Key findings
- Average star rating has stayed essentially flat from 2015–2023, though this is scoped by a known scraping limitation restricting `stars` to odd values only
- No statistically significant relationship between review length and star rating (Kruskal-Wallis H-test, p ≈ 0.991)
- Reviewers who did not recommend British Airways wrote significantly longer reviews on average than those who did (Mann-Whitney U test, p ≈ 8.28 × 10⁻²¹)

## SQL analysis
The same dataset was also loaded into PostgreSQL (hosted on Supabase) and explored with SQL:
- `sql/01_explore_columns.sql` — row count, rating summary, and value counts for traveller type, recommendation, and seat type
- `sql/02_clean_dates.sql` — converts the text dates (e.g. `1st August 2023`) into a real `date` column using `regexp_replace` and `to_date`; the true review range is 10 Nov 2015 to 1 Aug 2023
- `sql/03_rating_analysis.sql` — review counts and average star rating by year, recommendation, and seat type

SQL findings:
- Review counts per year are uneven (peak in 2016–2017, lowest in 2020–2021); 2015 and 2023 are partial years
- Average star rating is flat across the years (4.25–4.31 on the 1–9 scale), matching the Python analysis
- Ratings barely differ by recommendation (4.32 for yes, 4.25 for no) or seat type (4.14–4.32), so the star column carries little signal about satisfaction in this dataset
