# British Airways Customer Reviews — Data Analysis

Exploratory data analysis and cleaning of ~2,500 British Airways customer reviews (Skytrax-style), covering ratings, seat class, travel type, and review text.

## Goals
- Practice an end-to-end data analytics workflow: import, clean, explore, visualize
- Build a portfolio project using Python, pandas, and Jupyter
- Version-controlled with Git

## Project structure
- `data/raw/` — original, unmodified dataset
- `data/processed/` — cleaned dataset (generated by the notebook)
- `notebooks/` — analysis notebook(s)
